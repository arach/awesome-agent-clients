# Contributing

Thanks for helping map the agent-client ecosystem.

## Adding an entry

1. **One canonical link.** Prefer the GitHub repo; use the product homepage
   for closed-source tools.
2. **One factual sentence.** What it is + what it does. No marketing
   superlatives, no "best", no trailing period pile-ups.
3. **Pick a section.** Match the taxonomy (`## Contents`). If none fits,
   suggest one — we'll re-bucket on review.
4. **Format:** `- [Name](url) — description`
5. Stars, license, archived/dormant flags, and `drives:` metadata are
   regenerated from GitHub — you don't need to add them by hand.

## Bar for inclusion

- Actually runs, wraps, observes, or supports AI coding agents. Adjacent
  infrastructure (sandboxes, routers, memory layers) is in scope; generic
  LLM tools are not.
- Shipped software. Waitlist pages and README-only projects go in
  "Dormant & Archived (Notable)" at most.
- No duplicates — check `⌘F` first; moved/renamed repos get deduped by
  canonical `owner/name`.

This list is generated from structured data maintained in
[agentlist.io](https://www.agentlist.io); PRs here get folded back into the
source dataset so nothing gets lost.
